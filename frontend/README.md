# Frontend

React + Vite 前端，包含登录/注册、在线考试、成绩展示页面。

## 目录结构

```
frontend/src/
├── pages/          # 页面组件
├── components/     # 公共组件
├── context/        # 认证状态
└── services/       # API 请求
```

## 快速启动

```bash
npm install
npm run dev
```

访问 http://localhost:5173

详细说明见 [docs/module1-module3.md](../docs/module1-module3.md)
